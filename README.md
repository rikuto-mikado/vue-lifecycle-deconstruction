# Vue Lifecycle Deconstruction

This repository contains practice code and experiments focused on exploring and deconstructing Vue 3 lifecycle hooks.

## Overview

The primary goal of this project is to understand the behavior and execution order of Vue lifecycle hooks (Creation, Mounting, Updating, and Unmounting) within the Composition API.

## Features

- **Lifecycle Labs**: Dedicated components for experimenting with specific hooks (`onMounted`, `onUpdated`, `onUnmounted`, etc.).
- **Real-time Logger**: A utility to visualize when and in what order hooks are triggered.
- **Hands-on Examples**: Practical demonstrations of component lifecycle transitions.
